# classes-recipe

Classes that recipes and images inherit.

## Files

- [dtb-fit-image.bbclass](dtb-fit-image.bbclass) — Builds the multi-DTB FIT image qclinuxfitImage with its metadata and configurations.
- [image-adbd.bbclass](image-adbd.bbclass) — Installs adbd in an image and enables it with the enable-adbd image feature.
- [image_types_qcom.bbclass](image_types_qcom.bbclass) — Adds the qcomflash image type: a folder and tarball ready for QDL.
- [qcom-capsule.bbclass](qcom-capsule.bbclass) — Builds signed UEFI FMP capsules for firmware updates.
- [README.md](README.md) — Introduces this folder and indexes its contents.
