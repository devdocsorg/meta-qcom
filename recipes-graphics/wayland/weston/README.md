# Weston patches

Patches applied to Weston on Qualcomm machines.

## Files

- [0001-backend-drm-only-put-overlay-planes-on-the-per-output.patch](0001-backend-drm-only-put-overlay-planes-on-the-per-output.patch) — Puts overlay planes only on the per-output plane list in the DRM backend.
- [0001-compositor-skip-deferred-repaint-when-no-output-is-a.patch](0001-compositor-skip-deferred-repaint-when-no-output-is-a.patch) — Skips a deferred repaint when no output is active.
- [0001-libweston-avoid-duplicate-texture2D_swizzle-overload.patch](0001-libweston-avoid-duplicate-texture2D_swizzle-overload.patch) — Avoids duplicate texture2D_swizzle shader overloads.
- [0001-libweston-inline-color-pipeline-and-wireframe-helper.patch](0001-libweston-inline-color-pipeline-and-wireframe-helper.patch) — Inlines the colour pipeline and wireframe shader helpers.
