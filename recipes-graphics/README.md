# Graphics

Recipes and appends for the Adreno GPU user-space stack, its kernel driver, and the open-source graphics and Wayland components on Qualcomm machines.

## Folders

- [adreno/](adreno/README.md) — Installs the prebuilt Adreno OpenGL ES, Vulkan, and OpenCL libraries.
- [kgsl-dlkm/](kgsl-dlkm/README.md) — Builds the KGSL Adreno GPU kernel module and its udev rule.
- [mesa/](mesa/README.md) — Adds freedreno patches and settings to Mesa for Qualcomm machines.
- [msm-gbm-backend/](msm-gbm-backend/README.md) — Builds the MSM GBM backend library.
- [wayland/](wayland/README.md) — Adapts Weston and its start-up configuration for Qualcomm machines.
