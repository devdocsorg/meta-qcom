# recipes-graphics

Adreno GPU drivers and graphics stack changes.

## Folders

- [adreno/](adreno/README.md) — Packages the Adreno user-mode libraries.
- [kgsl-dlkm/](kgsl-dlkm/README.md) — Builds the KGSL GPU kernel module.
- [mesa/](mesa/README.md) — Adds freedreno changes to Mesa.
- [msm-gbm-backend/](msm-gbm-backend/README.md) — Builds the MSM GBM backend.
- [wayland/](wayland/README.md) — Adds Weston changes.
