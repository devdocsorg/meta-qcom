# Mesa patches

Patches applied to Mesa on Qualcomm machines.

## Files

- [0001-freedreno-a6xx-upload-dummy-sampler.patch](0001-freedreno-a6xx-upload-dummy-sampler.patch) — Uploads a dummy sampler on a6xx when textures are bound without samplers.
- [0001-freedreno-Add-chip-id-support-for-A830v1.patch](0001-freedreno-Add-chip-id-support-for-A830v1.patch) — Adds the chip ID for the Adreno A830v1 GPU.
- [0001-freedreno-Add-chip-support-for-a722.patch](0001-freedreno-Add-chip-support-for-a722.patch) — Adds support for the Adreno A722 GPU.
- [0002-rusticl-emit-image-texture-barriers.patch](0002-rusticl-emit-image-texture-barriers.patch) — Emits image and texture barriers after rusticl kernels.
- [0003-freedreno-a6xx-enable-f16-infinities.patch](0003-freedreno-a6xx-enable-f16-infinities.patch) — Enables f16 infinities in the freedreno a6xx driver.
- [README.md](README.md) — Indexes this folder.
