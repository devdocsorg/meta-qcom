# recipes-multimedia/imsdk

Recipes for the Qualcomm IMSDK GStreamer plugins.

## Files

- [gst-plugins-imsdk-base_2.0.2.bb](gst-plugins-imsdk-base_2.0.2.bb) — Builds the IMSDK GStreamer base libraries.
- [gst-plugins-imsdk-common.inc](gst-plugins-imsdk-common.inc) — Shares the IMSDK source, licence, and build settings.
- [gst-plugins-imsdk-oss_2.0.2.bb](gst-plugins-imsdk-oss_2.0.2.bb) — Builds the open-source IMSDK GStreamer plugins.
- [gst-plugins-imsdk-packaging.inc](gst-plugins-imsdk-packaging.inc) — Splits the IMSDK plugins and their runtime modules into packages.
- [gst-plugins-imsdk-prop_2.0.2.bb](gst-plugins-imsdk-prop_2.0.2.bb) — Builds the proprietary IMSDK GStreamer plugins.
- [README.md](README.md) — Introduces this folder and indexes its contents.
- [smart-venc-ctrl-algo_1.0.2.bb](smart-venc-ctrl-algo_1.0.2.bb) — Packages the prebuilt smart video encoder control libraries.
