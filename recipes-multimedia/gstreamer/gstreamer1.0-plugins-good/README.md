# plugins-good patches

Patches applied to gstreamer1.0-plugins-good on Qualcomm machines.

## Files

- [0001-v4l2-Add-support-for-V4L2_PIX_FMT_QC08C-format.patch](0001-v4l2-Add-support-for-V4L2_PIX_FMT_QC08C-format.patch) — Adds the V4L2_PIX_FMT_QC08C compressed format to the V4L2 plugin.
- [0002-v4l2videoenc-Set-format-on-capture-queue-before-enco.patch](0002-v4l2videoenc-Set-format-on-capture-queue-before-enco.patch) — Sets the capture queue format before encoding starts.
- [0004-v4l2videodec-Prefer-colorimetry-from-acquired-caps.patch](0004-v4l2videodec-Prefer-colorimetry-from-acquired-caps.patch) — Prefers colorimetry from the acquired caps in the V4L2 decoder.
- [0006-v4l2object-providing-aligned-size-when-propose-alloc.patch](0006-v4l2object-providing-aligned-size-when-propose-alloc.patch) — Provides the aligned buffer size in allocation proposals.
- [0007-v4l2-Drop-empty-bytesused-0-buffers.patch](0007-v4l2-Drop-empty-bytesused-0-buffers.patch) — Drops V4L2 buffers with no payload.
- [0008-v4l2-Handle-GAP-buffer-in-encoder.patch](0008-v4l2-Handle-GAP-buffer-in-encoder.patch) — Handles gap buffers in the V4L2 encoder.
- [0010-v4l2-Add-support-for-V4L2_PIX_FMT_QC10C-format.patch](0010-v4l2-Add-support-for-V4L2_PIX_FMT_QC10C-format.patch) — Adds the V4L2_PIX_FMT_QC10C compressed format to the V4L2 plugin.
- [0011-pulse-NULL-check-before-de-reference.patch](0011-pulse-NULL-check-before-de-reference.patch) — Adds a NULL check to the PulseAudio plugin.
- [0012-pulse-add-pulsedirectsink-element.patch](0012-pulse-add-pulsedirectsink-element.patch) — Adds the pulsedirectsink element to the PulseAudio plugin.
