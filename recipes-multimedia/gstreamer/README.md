# GStreamer appends

Appends and patches that add Qualcomm compressed formats and fixes to the GStreamer plugin sets on Qualcomm machines.

## Folders

- [gstreamer1.0-plugins-bad/](gstreamer1.0-plugins-bad/README.md) — Holds the Wayland and waylandsink patches.
- [gstreamer1.0-plugins-base/](gstreamer1.0-plugins-base/README.md) — Holds the video format and video meta patches.
- [gstreamer1.0-plugins-good/](gstreamer1.0-plugins-good/README.md) — Holds the V4L2 and PulseAudio patches.

## Files

- [gstreamer1.0-plugins-bad_%.bbappend](gstreamer1.0-plugins-bad_%25.bbappend) — Applies the plugins-bad patches on Qualcomm machines.
- [gstreamer1.0-plugins-base_%.bbappend](gstreamer1.0-plugins-base_%25.bbappend) — Applies the plugins-base patches on Qualcomm machines.
- [gstreamer1.0-plugins-good_%.bbappend](gstreamer1.0-plugins-good_%25.bbappend) — Applies the plugins-good patches on Qualcomm machines.
- [README.md](README.md) — Indexes this folder.
