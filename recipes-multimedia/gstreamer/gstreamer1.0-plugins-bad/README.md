# plugins-bad patches

Patches applied to gstreamer1.0-plugins-bad on Qualcomm machines.

## Files

- [0001-wayland-Add-support-for-NV12_Q08C-compressed-8-bit-f.patch](0001-wayland-Add-support-for-NV12_Q08C-compressed-8-bit-f.patch) — Adds the compressed 8-bit NV12_Q08C format to the Wayland library.
- [0002-waylandsink-Release-pending-buffers-during-PAUSED-to.patch](0002-waylandsink-Release-pending-buffers-during-PAUSED-to.patch) — Releases pending waylandsink buffers when pausing.
- [0003-waylandsink-support-gap-buffers.patch](0003-waylandsink-support-gap-buffers.patch) — Makes waylandsink handle gap buffers.
