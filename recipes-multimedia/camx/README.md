# camx

Recipes for the kernel and header parts of the Qualcomm CamX camera stack on ARMv8 machines.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [camx-dlkm_1.0.6.bb](camx-dlkm_1.0.6.bb) — Builds the out-of-tree Qualcomm camera driver (CAMX) as kernel modules and installs its userspace API headers.
- [camxcommon-headers_1.0.48.bb](camxcommon-headers_1.0.48.bb) — Installs the prebuilt headers shared by all Qualcomm CamX stacks.
