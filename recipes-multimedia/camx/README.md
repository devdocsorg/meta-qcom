# Camera driver and headers

Recipes for the CamX camera kernel driver and the headers shared by the CamX stacks.

## Files

- [camx-dlkm_1.0.6.bb](camx-dlkm_1.0.6.bb) — Builds the camera kernel modules and installs their UAPI headers.
- [camxcommon-headers_1.0.48.bb](camxcommon-headers_1.0.48.bb) — Installs the prebuilt CamX common headers.
- [README.md](README.md) — Indexes this folder.
