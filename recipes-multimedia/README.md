# Multimedia

Recipes and appends for Qualcomm camera, computer vision, video, and GStreamer components.

## Folders

- [camx/](camx/README.md) — Builds the camera kernel driver and installs the CamX headers.
- [fastcv/](fastcv/README.md) — Installs the prebuilt FastCV computer vision libraries.
- [gstreamer/](gstreamer/README.md) — Adds Qualcomm format support and fixes to the GStreamer plugin sets.
- [imsdk/](imsdk/README.md) — Builds the IMSDK GStreamer plugins and the Smart Video Encoder Control libraries.
