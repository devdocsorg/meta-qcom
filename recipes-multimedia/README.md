# recipes-multimedia

Camera, computer vision, GStreamer, and IMSDK recipes.

## Folders

- [camx/](camx/README.md) — Builds the camera kernel driver and headers.
- [fastcv/](fastcv/README.md) — Packages the FastCV library.
- [gstreamer/](gstreamer/README.md) — Adds Qualcomm formats and fixes to GStreamer.
- [imsdk/](imsdk/README.md) — Builds the IMSDK GStreamer plugins.
