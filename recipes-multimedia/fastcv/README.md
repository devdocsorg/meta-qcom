# fastcv

Recipe for the prebuilt Qualcomm FastCV library on ARMv8 machines. Machines pull in the DSP package for their board, such as `qcom-fastcv-binaries-qcs615-ride-dsp`.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [qcom-fastcv-binaries_1.8.9.bb](qcom-fastcv-binaries_1.8.9.bb) — Installs the prebuilt FastCV image processing and computer vision library, its header, and the per-board compute DSP libraries.
