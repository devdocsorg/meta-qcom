# Hexagon DSP binaries

Recipes that package the Hexagon DSP libraries and executables per board and DSP.

## Files

- [README.md](README.md) — Indexes this folder.
- [hexagon-dsp-binaries.inc](hexagon-dsp-binaries.inc) — Installs the binaries, defines one package per board and DSP, and checks their symlinks.
- [hexagon-dsp-binaries_20260910.bb](hexagon-dsp-binaries_20260910.bb) — Selects the 20260910 release and its licence checksums.
