# recipes-bsp/lk

Recipes for the Little Kernel (LK) boot loader of the DragonBoard 410c and 820c.

## Files

- [lk-db410c-sd-boot_git.bb](lk-db410c-sd-boot_git.bb) — Builds LK for booting the DragonBoard 410c from an SD card.
- [lk-db410c_git.bb](lk-db410c_git.bb) — Builds LK for the DragonBoard 410c.
- [lk-db820c_git.bb](lk-db820c_git.bb) — Builds LK with verified boot for the DragonBoard 820c.
- [lk.inc](lk.inc) — Shares the LK fetch, build, signing, and deployment.
- [README.md](README.md) — Introduces this folder and indexes its contents.
