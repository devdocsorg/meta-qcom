# recipes-bsp/firmware

Recipes that package prebuilt firmware.

## Files

- [camxfirmware-hamoa_1.0.6.bb](camxfirmware-hamoa_1.0.6.bb) — Packages the Hamoa camera firmware, shared with Purwa.
- [camxfirmware-kodiak_1.0.7.bb](camxfirmware-kodiak_1.0.7.bb) — Packages the Kodiak camera firmware.
- [camxfirmware-lemans_1.0.7.bb](camxfirmware-lemans_1.0.7.bb) — Packages the Lemans camera firmware, shared with Monaco.
- [camxfirmware-talos_1.0.1.bb](camxfirmware-talos_1.0.1.bb) — Packages the Talos camera firmware.
- [firmware-ath6kl_git.bb](firmware-ath6kl_git.bb) — Packages extra firmware for the Qualcomm Atheros AR6004.
- [firmware-qcom-qcm6490-idp.bb](firmware-qcom-qcm6490-idp.bb) — Placeholder for the QCM6490-IDP firmware, which another layer provides.
- [firmware-qcom-rb3gen2.bb](firmware-qcom-rb3gen2.bb) — Placeholder for the RB3 Gen 2 firmware, which another layer provides.
- [firmware-qcom.inc](firmware-qcom.inc) — Shares the packaging, splitting, and compression of Qualcomm firmware recipes.
- [README.md](README.md) — Introduces this folder and indexes its contents.
