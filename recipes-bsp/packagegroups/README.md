# packagegroups

Packagegroup recipes that collect the firmware, Hexagon DSP binaries, kernel modules, and core userspace that Qualcomm machines need. Machine configurations and image recipes install these groups by package name, such as `packagegroup-rb3gen2-firmware`; firmware for GPU, Wi-Fi, and Bluetooth is only recommended when the matching distro features are enabled.
