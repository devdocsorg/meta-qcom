# recipes-bsp

Board support recipes: firmware, boot loaders, partitions, firmware images, and machine packagegroups.

## Folders

- [devicetree/](devicetree/README.md) — Builds a placeholder device tree for the generic machine.
- [firmware/](firmware/README.md) — Packages camera and other device firmware.
- [firmware-boot/](firmware-boot/README.md) — Deploys the boot firmware and CDT binaries for each platform.
- [hexagon-dsp-binaries/](hexagon-dsp-binaries/README.md) — Packages the Hexagon DSP libraries and executables.
- [images/](images/README.md) — Builds small ramdisks that carry each board's firmware.
- [lk/](lk/README.md) — Builds the Little Kernel boot loader for DragonBoards.
- [packagegroups/](packagegroups/README.md) — Groups the packages each machine needs.
- [partition/](partition/README.md) — Deploys partition tables and partition tools.
- [u-boot/](u-boot/README.md) — Builds U-Boot and its FIT boot script for Qualcomm boards.
