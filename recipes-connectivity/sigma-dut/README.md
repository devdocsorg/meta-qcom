# sigma-dut

Holds the recipe for [sigma-dut](https://github.com/qualcomm/sigma-dut), the tool that runs Wi-Fi Alliance (WFA) certification tests on Qualcomm Atheros (QCA) Wi-Fi devices.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [sigma-dut_git.bb](sigma-dut_git.bb) — Builds [sigma-dut](https://github.com/qualcomm/sigma-dut) against `libnl` and installs it into `sbindir`.
