# conf/machine

One configuration per supported machine; set `MACHINE` or a kas file's `machine` to one of these names.

## Folders

- [include/](include/README.md) — Shared SoC, boot, and device tree settings that machines require.

## Files

- [glymur-crd.conf](glymur-crd.conf) — Configures the Qualcomm Glymur Compute Reference Device.
- [iq-615-evk.conf](iq-615-evk.conf) — Configures the Qualcomm IQ-615 Evaluation Kit, based on QCS615.
- [iq-8275-evk.conf](iq-8275-evk.conf) — Configures the Qualcomm IQ-8275 Evaluation Kit, based on QCS8275.
- [iq-9075-evk-open-fw-spl.conf](iq-9075-evk-open-fw-spl.conf) — Configures the IQ-9075 Evaluation Kit with open boot firmware and U-Boot SPL.
- [iq-9075-evk-open-fw.conf](iq-9075-evk-open-fw.conf) — Configures the IQ-9075 Evaluation Kit with open boot firmware.
- [iq-9075-evk.conf](iq-9075-evk.conf) — Configures the Qualcomm IQ-9075 Evaluation Kit, based on QCS9075.
- [iq-x5121-evk.conf](iq-x5121-evk.conf) — Configures the Qualcomm Purwa IoT Evaluation Kit, based on IQ-X5121.
- [iq-x7181-evk.conf](iq-x7181-evk.conf) — Configures the Qualcomm Hamoa IoT Evaluation Kit, based on IQ-X7181.
- [kaanapali-mtp.conf](kaanapali-mtp.conf) — Configures the Qualcomm Kaanapali development kit.
- [qcm6490-idp.conf](qcm6490-idp.conf) — Configures the QCM6490 Integrated Development Platform.
- [qcom-armv7a.conf](qcom-armv7a.conf) — Configures one 32-bit machine for Snapdragon ARMv7-a boards (S4 and later).
- [qcom-armv8a.conf](qcom-armv8a.conf) — Configures one generic 64-bit machine for many Snapdragon ARMv8-a boards.
- [qcs615-ride.conf](qcs615-ride.conf) — Configures the QCS615 ADP Air Beta Evaluation Kit.
- [qcs6490-rb3gen2-core-kit.conf](qcs6490-rb3gen2-core-kit.conf) — Keeps the older name for rb3gen2-core-kit.conf.
- [qcs8300-ride-sx.conf](qcs8300-ride-sx.conf) — Configures the QCS8300 Ride SX Beta Evaluation Kit.
- [qcs9100-ride-sx.conf](qcs9100-ride-sx.conf) — Configures the QCS9100 Ride SX Beta Evaluation Kit.
- [qrb2210-rb1-core-kit.conf](qrb2210-rb1-core-kit.conf) — Keeps the older name for rb1-core-kit.conf.
- [rb1-core-kit.conf](rb1-core-kit.conf) — Configures the Qualcomm RB1 development kit (core kit), with QRB2210.
- [rb3gen2-core-kit-open-fw.conf](rb3gen2-core-kit-open-fw.conf) — Configures the RB3 Gen 2 core kit with open boot firmware.
- [rb3gen2-core-kit.conf](rb3gen2-core-kit.conf) — Configures the Qualcomm RB3 Gen 2 development kit (core kit), with QCS6490.
- [README.md](README.md) — Introduces this folder and indexes its contents.
- [sdx75-idp.conf](sdx75-idp.conf) — Configures the Qualcomm SDX75 IDP board.
- [shikra-evk.conf](shikra-evk.conf) — Configures the Qualcomm Shikra Alpha Evaluation Kit.
- [sm8750-mtp.conf](sm8750-mtp.conf) — Configures the Qualcomm SM8750 development kit.
