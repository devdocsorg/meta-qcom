# ai

Recipes and appends that BitBake parses only when the `ai` layer collection from [meta-ai](https://github.com/qualcomm-linux/meta-ai) is in the build.

## Folders

- [recipes-ml/](recipes-ml/README.md) — The ONNX Runtime QNN execution provider recipe.
- [recipes-multimedia/](recipes-multimedia/README.md) — An append that enables the ONNX inference plugin in the IMSDK GStreamer plugins.
