# dynamic-layers

Recipes and appends that conf/layer.conf adds only when the named layer collection is present.

## Folders

- [ai/](ai/README.md) — Adds recipes for the ai collection of [meta-ai](https://github.com/qualcomm-linux/meta-ai).
- [meta-arm/](meta-arm/README.md) — Adds Trusted Firmware-A, OP-TEE, and capsule recipes for [meta-arm](https://git.yoctoproject.org/meta-arm).
- [openembedded-layer/](openembedded-layer/README.md) — Adds recipes and appends that need meta-oe.
- [qcom-distro/](qcom-distro/README.md) — Adds appends for [meta-qcom-distro](https://github.com/qualcomm-linux/meta-qcom-distro).
- [selinux/](selinux/README.md) — Adds SELinux kernel and policy changes for [meta-selinux](https://git.yoctoproject.org/meta-selinux).
- [virtualization-layer/](virtualization-layer/README.md) — Adds container runtime changes for [meta-virtualization](https://git.yoctoproject.org/meta-virtualization).
