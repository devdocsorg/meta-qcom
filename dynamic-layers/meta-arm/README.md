# Arm layer additions

Recipes used when [meta-arm](https://git.yoctoproject.org/meta-arm) is in the build.

## Folders

- [recipes-bsp/](recipes-bsp/README.md) — Trusted Firmware-A recipes.
- [recipes-devtools/](recipes-devtools/README.md) — Capsule generation tools.
- [recipes-firmware/](recipes-firmware/README.md) — UEFI capsule firmware recipe.
- [recipes-security/](recipes-security/README.md) — OP-TEE recipes, appends, and package group.
