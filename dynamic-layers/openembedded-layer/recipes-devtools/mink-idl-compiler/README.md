# mink-idl-compiler

Builds the Mink IDL compiler, which generates header files from Mink interface descriptions; minkipc uses its native build.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [mink-idl-compiler-crates.inc](mink-idl-compiler-crates.inc) — Lists the Rust crates from `Cargo.lock` with their checksums for the mink-idl-compiler recipe, generated by `bitbake -c update_crates mink-idl-compiler`.
- [mink-idl-compiler_0.2.3.bb](mink-idl-compiler_0.2.3.bb) — Builds version 0.2.3 of [mink-idl-compiler](https://github.com/quic/mink-idl-compiler) with Cargo, for target and native.
