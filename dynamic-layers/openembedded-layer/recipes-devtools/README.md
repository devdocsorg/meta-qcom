# recipes-devtools

Developer tool recipes and appends that BitBake parses only when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [abseil-cpp/](abseil-cpp/README.md) — A pinned copy of the Abseil C++ recipe.
- [android-tools/](android-tools/README.md) — Recipes and appends that control how adbd and its USB gadget start.
- [mink-idl-compiler/](mink-idl-compiler/README.md) — The Mink IDL compiler recipe.
