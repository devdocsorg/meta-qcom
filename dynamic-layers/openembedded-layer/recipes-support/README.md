# recipes-support

Sensor and computer vision recipes and appends that BitBake parses only when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [libssc/](libssc/README.md) — The libssc sensor library recipe.
- [opencv/](opencv/README.md) — An append that enables OpenCV tests and FastCV support.
- [sensors/](sensors/README.md) — The Sensing Hub library and prebuilt Qualcomm sensor binaries.
