# recipes-multimedia

Camera and IMSDK GStreamer recipes and appends that BitBake parses only when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [camera-service/](camera-service/README.md) — The Qualcomm embedded camera service recipe.
- [camx/](camx/README.md) — Prebuilt CamX camera libraries, one recipe per SoC platform.
- [imsdk/](imsdk/README.md) — IMSDK GStreamer plugin feature appends and the IMSDK Python bindings.
