# dynamic-layers/openembedded-layer/recipes-multimedia/camx

Recipes that package the prebuilt CamX camera libraries for each platform.

## Files

- [camxlib-hamoa_1.0.48.bb](camxlib-hamoa_1.0.48.bb) — Packages the Hamoa CamX libraries.
- [camxlib-kodiak_1.0.44.bb](camxlib-kodiak_1.0.44.bb) — Packages the Kodiak CamX libraries, CHI developer kit, and tuning binaries.
- [camxlib-lemans_1.0.48.bb](camxlib-lemans_1.0.48.bb) — Packages the Lemans CamX libraries.
- [camxlib-shikra_1.0.48.bb](camxlib-shikra_1.0.48.bb) — Packages the Shikra CamX libraries.
- [camxlib-talos_1.0.48.bb](camxlib-talos_1.0.48.bb) — Packages the Talos CamX libraries.
- [common.inc](common.inc) — Shares the fetch, installation, and packaging of the CamX libraries.
- [README.md](README.md) — Introduces this folder and indexes its contents.
