# CamX camera libraries

Installs the prebuilt CamX camera engine, libraries, and CHI developer kit for each SoC.

## Files

- [README.md](README.md) — Indexes this folder.
- [camxlib-hamoa_1.0.48.bb](camxlib-hamoa_1.0.48.bb) — Installs CamX 1.0.48 for Hamoa with its DSP skel files.
- [camxlib-kodiak_1.0.44.bb](camxlib-kodiak_1.0.44.bb) — Installs CamX 1.0.44 for Kodiak.
- [camxlib-lemans_1.0.48.bb](camxlib-lemans_1.0.48.bb) — Installs CamX 1.0.48 for Lemans with the camera-nhx test data.
- [camxlib-shikra_1.0.48.bb](camxlib-shikra_1.0.48.bb) — Installs CamX 1.0.48 for Shikra.
- [camxlib-talos_1.0.48.bb](camxlib-talos_1.0.48.bb) — Installs CamX 1.0.48 for Talos.
- [common.inc](common.inc) — Shares the download, install, and packaging steps for the CamX recipes.
