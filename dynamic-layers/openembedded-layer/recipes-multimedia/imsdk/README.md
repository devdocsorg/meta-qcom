# IMSDK features

Enables IMSDK GStreamer features and builds its Python libraries.

## Files

- [README.md](README.md) — Indexes this folder.
- [gst-plugins-imsdk-oss_%.bbappend](gst-plugins-imsdk-oss_%25.bbappend) — Enables the ML, messaging, Python, Redis sink, sample, and C++ builder features.
- [gst-plugins-imsdk-prop_%.bbappend](gst-plugins-imsdk-prop_%25.bbappend) — Enables the camera plugins and camera applications.
- [gst-plugins-imsdk-python_2.0.2.bb](gst-plugins-imsdk-python_2.0.2.bb) — Builds the IMSDK GStreamer Python libraries version 2.0.2.
