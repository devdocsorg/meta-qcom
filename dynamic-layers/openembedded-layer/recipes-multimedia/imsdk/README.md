# dynamic-layers/openembedded-layer/recipes-multimedia/imsdk

IMSDK recipes and appends that need meta-oe.

## Files

- [gst-plugins-imsdk-oss_%.bbappend](gst-plugins-imsdk-oss_%.bbappend) — Enables the IMSDK features that need meta-oe.
- [gst-plugins-imsdk-prop_%.bbappend](gst-plugins-imsdk-prop_%.bbappend) — Enables the IMSDK camera plugins and applications.
- [gst-plugins-imsdk-python_2.0.2.bb](gst-plugins-imsdk-python_2.0.2.bb) — Builds the IMSDK GStreamer Python libraries.
- [README.md](README.md) — Introduces this folder and indexes its contents.
