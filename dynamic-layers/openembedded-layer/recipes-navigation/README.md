# recipes-navigation

Satellite positioning and location recipes and appends that BitBake parses only when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [gpsd/](gpsd/README.md) — An append and patch that add Qualcomm PDS support to gpsd.
- [location-client-api/](location-client-api/README.md) — The Qualcomm location HAL recipe.
