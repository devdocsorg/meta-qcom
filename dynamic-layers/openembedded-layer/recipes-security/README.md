# recipes-security

Recipes for talking to the Qualcomm Trusted Execution Environment (QTEE) that BitBake parses only when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [minkipc/](minkipc/README.md) — The MinkIPC library, QTEE supplicant, and trusted applications.
- [qcomtee/](qcomtee/README.md) — The QCOM-TEE library.

- [README.md](README.md) — Describes this folder and indexes its contents.
