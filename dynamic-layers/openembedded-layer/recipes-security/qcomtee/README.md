# qcomtee

Builds the QCOM-TEE library, which talks to QTEE through the QCOM-TEE driver in the Linux TEE subsystem.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [qcomtee_1.0.2.bb](qcomtee_1.0.2.bb) — Builds version 1.0.2 of [quic-teec](https://github.com/quic/quic-teec) with CMake, depending on qcbor.
