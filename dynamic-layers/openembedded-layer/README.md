# dynamic-layers/openembedded-layer

Recipes and appends that apply with the meta-oe layer of [meta-openembedded](https://github.com/openembedded/meta-openembedded).

## Folders

- [recipes-connectivity/](recipes-connectivity/README.md) — Holds modem changes.
- [recipes-devtools/](recipes-devtools/README.md) — Holds adb, Abseil, and the Mink IDL compiler.
- [recipes-multimedia/](recipes-multimedia/README.md) — Holds camera and IMSDK recipes.
- [recipes-navigation/](recipes-navigation/README.md) — Holds GNSS recipes.
- [recipes-security/](recipes-security/README.md) — Holds trusted execution client recipes.
- [recipes-support/](recipes-support/README.md) — Holds sensor and OpenCV recipes.
