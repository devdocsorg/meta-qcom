# OpenEmbedded layer additions

Recipes and appends used when the meta-oe layer from [meta-openembedded](https://github.com/openembedded/meta-openembedded) is in the build.

## Folders

- [recipes-connectivity/](recipes-connectivity/README.md) — Modem connectivity appends.
- [recipes-devtools/](recipes-devtools/README.md) — Development libraries, ADB configuration, and IDL compiler.
- [recipes-multimedia/](recipes-multimedia/README.md) — Camera and IMSDK multimedia recipes.
- [recipes-navigation/](recipes-navigation/README.md) — GNSS and location recipes.
- [recipes-security/](recipes-security/README.md) — Qualcomm TEE libraries and applications.
- [recipes-support/](recipes-support/README.md) — Sensor and OpenCV recipes.
