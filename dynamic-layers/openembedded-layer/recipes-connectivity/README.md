# recipes-connectivity

Appends that adapt the libqmi and ModemManager recipes from the meta-oe layer in [meta-openembedded](https://github.com/openembedded/meta-openembedded) to Qualcomm modems.

## Folders

- [libqmi/](libqmi/README.md) — An append that enables QRTR support in libqmi.
- [modemmanager/](modemmanager/README.md) — An append and patches that add Qualcomm modem support to ModemManager.
