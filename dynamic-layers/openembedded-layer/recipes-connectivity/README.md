# Connectivity appends

Appends that add Qualcomm modem support to [meta-oe](https://github.com/openembedded/meta-openembedded) connectivity recipes.

## Folders

- [libqmi/](libqmi/README.md) — Enables QRTR in libqmi.
- [modemmanager/](modemmanager/README.md) — Adds Qualcomm modem support to ModemManager.
