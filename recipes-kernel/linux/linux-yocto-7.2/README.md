# linux-yocto 7.2 files

Kernel metadata and patches that linux-yocto-qcom.inc and linux-yocto_7.2.bbappend add to linux-yocto 7.2.

## Folders

- [bsp/](bsp/README.md) — Holds the Qualcomm BSP kernel metadata.
- [hamoa-iot-evk-dts/](hamoa-iot-evk-dts/README.md) — Holds the Hamoa IoT EVK camera overlay patch.
- [workarounds/](workarounds/README.md) — Holds a patch that works around a board issue.

## Files

- [README.md](README.md) — Indexes this folder.
- [qcom.scc](qcom.scc) — Empty kernel feature file that the Qualcomm SRC_URI entry adds.
