# qcom-armv8a kernel metadata

Kernel machine description and configuration fragments for 64-bit Qualcomm SoCs.

## Files

- [README.md](README.md) — Indexes this folder.
- [qcom-armv8a-standard.scc](qcom-armv8a-standard.scc) — Defines the qcom-armv8a standard kernel machine and its features.
- [qcom-armv8a.scc](qcom-armv8a.scc) — Adds the common Qualcomm configuration and the SoC feature files.
- [qcom-extra.cfg](qcom-extra.cfg) — Enables extra options such as BPF, autofs, and USB Type-C.
- [qcom-msm8916.cfg](qcom-msm8916.cfg) — Enables the MSM8916 clock, pinctrl, and SoC drivers.
- [qcom-msm8916.scc](qcom-msm8916.scc) — Adds the MSM8916 configuration and its power-manager fragment.
- [qcom-msm8996.cfg](qcom-msm8996.cfg) — Enables the MSM8996 clock, pinctrl, and SoC drivers.
- [qcom-msm8996.scc](qcom-msm8996.scc) — Adds the MSM8996 configuration and its power-manager fragment.
- [qcom-qcm2290.cfg](qcom-qcm2290.cfg) — Enables the QCM2290 clock, pinctrl, and SoC drivers.
- [qcom-qcm2290.scc](qcom-qcm2290.scc) — Adds the QCM2290 configuration and its power-manager fragment.
- [qcom-qcm6490.cfg](qcom-qcm6490.cfg) — Enables the QCM6490 clock, pinctrl, and SoC drivers.
- [qcom-qcm6490.scc](qcom-qcm6490.scc) — Adds the QCM6490 configuration and its power-manager fragment.
- [qcom-rpm.cfg](qcom-rpm.cfg) — Enables the RPM (Resource Power Manager) drivers.
- [qcom-rpmh.cfg](qcom-rpmh.cfg) — Enables the RPMh (Resource Power Manager hardened) drivers.
- [qcom-sa8775p.cfg](qcom-sa8775p.cfg) — Enables the SA8775P clock, pinctrl, and SoC drivers.
- [qcom-sa8775p.scc](qcom-sa8775p.scc) — Adds the SA8775P configuration and its power-manager fragment.

- [qcom-sm6115.scc](qcom-sm6115.scc) — Adds the SM6115 configuration and its power-manager fragment.
- [qcom-sm8250.cfg](qcom-sm8250.cfg) — Enables the SM8250 clock, pinctrl, and SoC drivers.
- [qcom-sm8250.scc](qcom-sm8250.scc) — Adds the SM8250 configuration and its power-manager fragment.
- [qcom-sm8450.cfg](qcom-sm8450.cfg) — Enables the SM8450 clock, pinctrl, and SoC drivers.
- [qcom-sm8450.scc](qcom-sm8450.scc) — Adds the SM8450 configuration and its power-manager fragment.
- [qcom.cfg](qcom.cfg) — Enables the drivers common to Qualcomm ARMv8 SoCs.
