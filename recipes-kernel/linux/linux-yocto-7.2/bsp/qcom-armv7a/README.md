# qcom-armv7a kernel metadata

Kernel machine description and configuration fragments for 32-bit Qualcomm SoCs.

## Files

- [README.md](README.md) — Indexes this folder.
- [qcom-apq8064.cfg](qcom-apq8064.cfg) — Enables the APQ8064 clock, pinctrl, and SoC drivers.
- [qcom-apq8064.scc](qcom-apq8064.scc) — Adds the APQ8064 configuration.
- [qcom-armv7a-standard.scc](qcom-armv7a-standard.scc) — Defines the qcom-armv7a standard kernel machine and its features.
- [qcom-armv7a.scc](qcom-armv7a.scc) — Adds the common Qualcomm configuration and the SoC feature files.
- [qcom-msm8974.cfg](qcom-msm8974.cfg) — Enables the MSM8974 clock, pinctrl, and SoC drivers.
- [qcom-msm8974.scc](qcom-msm8974.scc) — Adds the MSM8974 configuration.
- [qcom-rpm.cfg](qcom-rpm.cfg) — Symlink to ../qcom-armv8a/qcom-rpm.cfg, the RPM driver configuration.
- [qcom.cfg](qcom.cfg) — Enables the drivers common to Qualcomm ARMv7 SoCs.
