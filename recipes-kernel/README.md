# recipes-kernel

Kernels, kernel modules, kernel firmware, and ESP and ramdisk images.

## Folders

- [images/](images/README.md) — Builds ESP and ramdisk images.
- [iris-video-module/](iris-video-module/README.md) — Builds the Iris video driver.
- [linux/](linux/README.md) — Builds the Qualcomm kernels and adapts linux-yocto.
- [linux-firmware/](linux-firmware/README.md) — Adapts linux-firmware for Qualcomm machines.
- [qps615-module/](qps615-module/README.md) — Builds the QPS615 PCIe Ethernet driver and firmware.
