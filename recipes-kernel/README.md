# Kernel recipes

Kernel, kernel-module, device tree, and boot-partition image recipes for Qualcomm machines.

## Folders

- [images/](images/README.md) — Builds the EFI System Partition and initramfs images.
- [iris-video-module/](iris-video-module/README.md) — Builds the Iris video driver module.
- [linux/](linux/README.md) — Kernel recipes and their configuration fragments and patches.
- [linux-firmware/](linux-firmware/README.md) — Adjusts linux-firmware for Qualcomm machines.
- [qps615-module/](qps615-module/README.md) — Builds the QPS615 PCIe Ethernet switch driver and firmware.
