# Video driver blacklists

modprobe files that choose between the upstream and Iris video drivers through update-alternatives.

## Files

- [README.md](README.md) — Indexes this folder.
- [blacklist-video.conf.venus](blacklist-video.conf.venus) — Blacklists the upstream Venus and qcom_iris drivers.
- [blacklist-video.conf.vidc](blacklist-video.conf.vidc) — Blacklists the `iris_vpu` driver.
