# classes

Classes that machine or build configuration enables globally, for example through KERNEL_CLASSES or INHERIT.

## Files

- [linux-qcom-bootimg.bbclass](linux-qcom-bootimg.bbclass) — Builds Android boot images for each device tree with skales mkbootimg.
- [linux-qcom-dtbbin.bbclass](linux-qcom-dtbbin.bbclass) — Packs each device tree, and the multi-DTB FIT image, into DTB partition images.
- [qli-mirrors.bbclass](qli-mirrors.bbclass) — Adds the Qualcomm Linux download mirror as a fetch fallback.
- [README.md](README.md) — Introduces this folder and indexes its contents.
- [uki-esp-image.bbclass](uki-esp-image.bbclass) — Places a unified kernel image in an ESP image.
