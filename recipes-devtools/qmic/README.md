# qmic

Holds the recipe for [qmic](https://github.com/linux-msm/qmic), the QMI compiler, built from a pinned Git revision.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [qmic_git.bb](qmic_git.bb) — Builds and installs [qmic](https://github.com/linux-msm/qmic) for the target, the build host, and the SDK.
