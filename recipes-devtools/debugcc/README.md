# debugcc

Holds the recipe for [debugcc](https://github.com/linux-msm/debugcc), a command-line tool for debugging the clock controllers of Qualcomm SoCs.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [debugcc_git.bb](debugcc_git.bb) — Builds [debugcc](https://github.com/linux-msm/debugcc) with Meson from a pinned Git revision.
