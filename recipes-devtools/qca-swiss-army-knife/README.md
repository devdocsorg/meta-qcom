# QCA driver utilities

Recipe for qca-swiss-army-knife and the layer scripts that generate board-2.json files for ath10k and ath11k board data.

## Folders

- [qca-swiss-army-knife/](qca-swiss-army-knife/README.md) — Holds the recipe patch and the board-2.json generator scripts.

## Files

- [qca-swiss-army-knife_git.bb](qca-swiss-army-knife_git.bb) — Builds qca-swiss-army-knife and installs its scripts with the layer generators.
- [README.md](README.md) — Indexes this folder.
