# pil-squasher

Holds the recipe for [pil-squasher](https://github.com/linux-msm/pil-squasher), which converts Qualcomm firmware images from the MDT format to the MBN format.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [pil-squasher_git.bb](pil-squasher_git.bb) — Builds and installs [pil-squasher](https://github.com/linux-msm/pil-squasher) for the target, the build host, and the SDK.
