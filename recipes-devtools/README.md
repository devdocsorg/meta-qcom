# Development tools

Recipes for host and target tools used to flash, sign, inspect, and debug Qualcomm boards and firmware.

## Folders

- [debugcc/](debugcc/README.md) — Builds the Qualcomm clock controller debugging tool.
- [pil-squasher/](pil-squasher/README.md) — Builds the tool that converts split MDT firmware into single MBN files.
- [qc-image-unpacker/](qc-image-unpacker/README.md) — Builds the Android Qualcomm image unpacker and its patches.
- [qca-swiss-army-knife/](qca-swiss-army-knife/README.md) — Builds the QCA driver development utilities and board-file JSON generators.
- [qdl/](qdl/README.md) — Builds the Qualcomm Download tool for flashing boards over USB.
- [qmic/](qmic/README.md) — Builds the QMI compiler.
- [qtestsign/](qtestsign/README.md) — Builds the tool that test-signs ELF Qualcomm firmware images.
- [skales/](skales/README.md) — Builds the skales tools that create Qualcomm boot images.
- [swiv-build-utility/](swiv-build-utility/README.md) — Builds the tool that adds a SWIV segment to boot firmware ELF images.
