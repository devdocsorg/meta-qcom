# recipes-devtools

Tools for building, signing, inspecting, and flashing Qualcomm images.

## Folders

- [debugcc/](debugcc/README.md) — Builds the clock controller debugging tool.
- [pil-squasher/](pil-squasher/README.md) — Builds the MDT to MBN converter.
- [qc-image-unpacker/](qc-image-unpacker/README.md) — Builds the Android Qualcomm image unpacker.
- [qca-swiss-army-knife/](qca-swiss-army-knife/README.md) — Packages the QCA driver development utilities.
- [qdl/](qdl/README.md) — Builds the Qualcomm download (flashing) tool.
- [qmic/](qmic/README.md) — Builds the QMI compiler.
- [qtestsign/](qtestsign/README.md) — Packages the firmware test-signing tool.
- [skales/](skales/README.md) — Packages the boot image tools.
- [swiv-build-utility/](swiv-build-utility/README.md) — Packages the SWIV ELF annotation tool.
