# recipes-support

Qualcomm support services, libraries, and initramfs modules.

## Folders

- [abl2esp/](abl2esp/README.md) — Deploys the ABL replacement that boots from the ESP.
- [fastrpc/](fastrpc/README.md) — Builds FastRPC.
- [hexagonrpc/](hexagonrpc/README.md) — Builds an alternative FastRPC implementation for sensors.
- [initrdscripts/](initrdscripts/README.md) — Adds an initramfs module that copies kernel modules.
- [libdmabufheap/](libdmabufheap/README.md) — Builds the DMA-BUF heap library.
- [libvmmem/](libvmmem/README.md) — Builds the libvmmem library.
- [pd-mapper/](pd-mapper/README.md) — Builds the protection domain mapper.
- [qbootctl/](qbootctl/README.md) — Builds the A/B boot control tool.
- [qmi-framework/](qmi-framework/README.md) — Builds the QMI framework.
- [qrtr/](qrtr/README.md) — Builds the QRTR tools and library.
- [rmtfs/](rmtfs/README.md) — Builds the remote file system service.
- [rpmsg-export/](rpmsg-export/README.md) — Builds rpmsgexport.
- [rust-android-sparse/](rust-android-sparse/README.md) — Builds the Android sparse image tool.
- [time-services/](time-services/README.md) — Builds the modem time sync daemon.
- [tqftpserv/](tqftpserv/README.md) — Builds the TFTP server over QRTR.
- [userspace-resource-manager/](userspace-resource-manager/README.md) — Builds the resource management daemon.
