# pd-mapper

Recipe for the Qualcomm protection domain mapper, which the SDX75 SoC include adds to every image.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [pd-mapper_1.1.bb](pd-mapper_1.1.bb) — Builds the `pd-mapper` service, which answers queries about which remote processor hosts each protection domain, with its systemd unit.
