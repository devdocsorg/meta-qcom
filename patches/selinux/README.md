# patches/selinux

Patches that ci/qcom-distro.yml applies to [meta-selinux](https://git.yoctoproject.org/meta-selinux).

## Files

- [0001-libsepol-enable-nativesdk.patch](0001-libsepol-enable-nativesdk.patch) — Enables nativesdk builds of libsepol.
- [0002-libselinux-enable-nativesdk.patch](0002-libselinux-enable-nativesdk.patch) — Enables nativesdk builds of libselinux.
- [0003-libselinux-python-fix-the-build-against-swig-4.5.0.patch](0003-libselinux-python-fix-the-build-against-swig-4.5.0.patch) — Fixes the libselinux-python build with SWIG 4.5.0.
- [README.md](README.md) — Introduces this folder and indexes its contents.
