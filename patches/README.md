# Patches for other layers

Patches that `ci/base.yml` and `ci/qcom-distro.yml` apply with kas to the
layers they check out, until the fixes are available upstream.

## Folders

- [oe-core/](oe-core/README.md) — Patches for [openembedded-core](https://github.com/openembedded/openembedded-core).
- [selinux/](selinux/README.md) — Patches for [meta-selinux](https://git.yoctoproject.org/meta-selinux).
