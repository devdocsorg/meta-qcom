# patches/oe-core

- [0001-linux-firmware-backport-shikra-wlan-firmware-support.patch](0001-linux-firmware-backport-shikra-wlan-firmware-support.patch) — Backports Shikra WLAN firmware support to linux-firmware.
- [0003-uboot-sign-keep-the-SPL-BSS-padding-when-reassembling.patch](0003-uboot-sign-keep-the-SPL-BSS-padding-when-reassembling.patch) — Keeps the SPL BSS padding when uboot-sign reassembles the SPL binary.
- [README.md](README.md) — Introduces this folder and indexes its contents.
