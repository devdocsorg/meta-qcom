# Documentation

Open [site/index.html](site/index.html) directly in a browser to read the
generated site; it needs no HTTP server or documentation tools.

Edit the [source](source/README.md), follow the
[development environment walkthrough](source/contributing/DEVELOPMENT.md), and
commit the source and the regenerated site together.

Generated [third-party asset notices](site/THIRD_PARTY_LICENSES.txt) preserve
the licences of the JavaScript and styles that the site redistributes.

## Folders

- [source/](source/README.md) — Contains the authoritative guides and the documentation build configuration.
- [site/](site/index.html) — Contains the generated, locally browsable HTML site and its assets.

## Files

- [README.md](README.md) — Points to the documentation source, built site, and build walkthrough.
- [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) — Retains the licence notices for documentation tooling and templates adapted from other projects.
