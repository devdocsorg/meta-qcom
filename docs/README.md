# Documentation

Open [site/index.html](site/index.html) directly in a browser to read the
generated site; no HTTP server or documentation tools are needed. Edit the
[source](source/README.md), rebuild it as the
[development walkthrough](source/contributing/DEVELOPMENT.md) describes, and
commit the source and regenerated site together.

The site's [third-party asset notices](site/THIRD_PARTY_LICENSES.txt) keep the
licences of the JavaScript and styles that Sphinx bundles.

## Folders

- [source/](source/README.md) — Holds the authoritative guides and the documentation build configuration.
- [site/](site/index.html) — Holds the generated, locally browsable HTML site and its assets.

## Files

- [README.md](README.md) — Points to the documentation source, the built site, and the build walkthrough.
