do_install¶

Install the DSP binaries with the upstream make install into D.

Example¶

bitbake -c install hexagon-dsp-binaries

Function has no arguments.

Exit codes¶

  • 0: The DSP binaries are in the install directory.

  • >0: The make install step failed; BitBake stops the task.

Python functions¶

populate_packages:prepend¶

populate_packages:prepend(d)

Split each DSP configuration YAML file into its own hexagon-dsp-binaries-<board>-config package before packaging.

Parameters:

d (bb.data_smart.DataSmart) – The recipe datastore.

Returns:

The config packages are added to PACKAGES.

Return type:

None

Example

bitbake -c package hexagon-dsp-binaries

package_qa_check_symlinks¶

package_qa_check_symlinks(pkg, d)

Report symlinks in a package whose targets are missing from it, naming the package that provides the target when that package is not in RDEPENDS.

Parameters:

  • pkg (str) – Package to check.

  • d (bb.data_smart.DataSmart) – The recipe datastore.

Returns:

Problems are reported through oe.qa.handle_error as the hexagon-dsp-binaries-symlink-deps QA check, a warning by default.

Return type:

None

Example

QAPKGTEST[hexagon-dsp-binaries-symlink-deps] = "package_qa_check_symlinks"
