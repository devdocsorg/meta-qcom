do_install:append¶

Add the camera driver UAPI headers for the default and Kodiak camera stacks under ${includedir}/camx.

Example¶

bitbake -c install camx-dlkm

Function has no arguments.

Exit codes¶

  • 0: The headers are in the install directory.

  • >0: An install command failed; BitBake stops the task.
