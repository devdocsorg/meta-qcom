meta-qcom documentation¶

meta-qcom is the OpenEmbedded and Yocto Project hardware enablement layer for Qualcomm platforms. Start with the flashing tutorial, look up build settings in the configuration reference, or prepare a change with the development setup.

Folders¶

  • user/ — Holds the tutorial, configuration reference, and production security guidance.

  • contributing/ — Holds the contribution and development guides and the function reference.

  • .templates/ — Supplies the generated site’s entry-point redirect.

Files¶

  • Makefile — Provides the shared local and CI setup, build, and check commands.

  • README.md — Introduces the guides and supplies the site’s homepage.

  • conf.py — Configures Markdown rendering, the function reference, local navigation, and search.

  • requirements.txt — Declares the documentation packages.

  • requirements.lock — Locks direct and transitive documentation dependencies for reproducible builds.
