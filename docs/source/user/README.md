# User documentation

Follow the [build, flash, and boot tutorial](USAGE.md) to put an image on a board,
and use the [configuration reference](CONFIGURATION.md) to choose or change machine
and build settings.

## Files

- [README.md](README.md) — Introduces the user documentation.
- [USAGE.md](USAGE.md) — Builds an image with kas, flashes it, and logs in on the board.
- [flashing.md](flashing.md) — Builds the QDL tool, prepares the board, and flashes images over USB.
- [CONFIGURATION.md](CONFIGURATION.md) — Documents the layer, machine, kas, and environment settings.
- [security-recommendations.md](security-recommendations.md) — Recommends hardening settings for production builds.
