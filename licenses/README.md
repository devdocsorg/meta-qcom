# Qualcomm licences

Licence agreements that Qualcomm binary recipes name in `LICENSE`;
`conf/layer.conf` adds this folder to `LICENSE_PATH`.

## Files

- [README.md](README.md) — Indexes this folder.
- [LICENSE.qcom](LICENSE.qcom) — Qualcomm Technologies licence agreement for recipes that use `LicenseRef-LICENSE.qcom`.
- [LICENSE.qcom-2](LICENSE.qcom-2) — Second Qualcomm Technologies licence agreement, for recipes that use `LicenseRef-LICENSE.qcom-2`.
