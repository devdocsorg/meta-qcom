# Python library

Python modules that the layer adds to BitBake's module search path through
`addpylib` in `conf/layer.conf`, plus the layer's oe-selftest cases.

## Folders

- [oeqa/](oeqa/README.md) — Holds test cases that OE-Core's test framework discovers.
- [qcom/](qcom/README.md) — Holds the `qcom` Python package used by the layer's classes.
