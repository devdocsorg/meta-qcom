# Test tools and images

Recipes for board test tools, diagnostic services, and the initramfs images used for bring-up and testing.

## Folders

- [bootrr/](bootrr/README.md) — Installs the bootrr board test scripts.
- [diag/](diag/README.md) — Builds the open-source DIAG router.
- [diag-router/](diag-router/README.md) — Installs the prebuilt diagnostic router.
- [images/](images/README.md) — Defines the test and bring-up initramfs images.
- [libdiag/](libdiag/README.md) — Installs the prebuilt diagnostic library and utilities.
- [mybw/](mybw/README.md) — Builds the memory read bandwidth test.
